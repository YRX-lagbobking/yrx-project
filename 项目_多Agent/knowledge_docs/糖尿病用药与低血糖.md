# 老年糖尿病用药与低血糖防范

## 一、血糖参考范围

- 空腹血糖常见参考范围：3.9~6.1 mmol/L。
- 空腹血糖 ≥7.0 mmol/L 或餐后 2 小时 ≥11.1 mmol/L 提示血糖偏高，需就医确认。
- 空腹血糖 <3.9 mmol/L 属于低血糖，老年人尤其危险，需立即处理。

## 二、低血糖的识别与处置

**典型表现**：心慌、出汗、手抖、饥饿感、面色苍白、注意力不集中。
**严重表现**：意识模糊、言语不清、行为异常、昏迷。

处置步骤（意识清醒时）：
1. 立即进食 15 克快速升糖食物（约 3 块方糖、半杯果汁、1 勺蜂蜜）。
2. 15 分钟后复测血糖，若仍 <3.9 mmol/L 再重复一次。
3. 血糖回升后补充少量主食，避免再次跌落。
4. 意识不清者禁止喂食，立即拨打 120 并通知家属。

## 三、老年人用药注意事项

1. 磺脲类、胰岛素等易致低血糖，用药后必须按时进餐。
2. 用药时间固定，建议使用分格药盒，家属协助核对。
3. 出现规律性餐前心慌出汗，应及时告知医生调整方案。
4. 不要轻信"降糖保健品"替代正规降糖药。

## 四、日常监测建议

- 每周至少监测 2~4 次空腹与餐后血糖，记录在册。
- 每 3 个月复查糖化血红蛋白。
- 每日检查足部皮肤，避免烫伤与破损。

> 免责声明：以上内容为健康科普，不构成诊断与处方，具体用药请遵医嘱。
