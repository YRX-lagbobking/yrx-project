# 老年人安全用药与漏服处理

## 一、安全用药五原则

1. **按时**：固定时间服药，建议设置手机/智能音箱提醒或使用分格药盒。
2. **按量**：不自行加量、减量；缓释片、肠溶片不可掰开或碾碎服用。
3. **对症**：不服用来源不明的"偏方""保健品"，避免与处方药相互作用。
4. **记录**：记录药名、剂量、时间与不良反应，就诊时带给医生。
5. **复查**：每 3~6 个月请医生评估用药方案，及时停用不必要药物。

## 二、漏服了怎么办

- **降压药**：想起时若距离下次服药 >12 小时，可补服一次；否则跳过，**不可加倍**。
- **降糖药**：若已接近下一餐，按原计划服用；出现低血糖表现按低血糖流程处理。
- **抗凝药**：漏服当天想起可补服，第二天按原剂量，切勿双倍补服。
- **任何情况**：拿不准时先电话咨询医生或药师，不要自行决定。

## 三、需要警惕的不良反应

| 表现 | 可能相关药物 |
| :--- | :--- |
| 干咳、下肢水肿 | 部分降压药（如 ACEI 类） |
| 心慌、出汗、手抖 | 降糖药、胰岛素 |
| 黑便、牙龈出血 | 抗凝/抗血小板药 |
| 头晕、站立不稳 | 降压药、镇静催眠药 |
| 皮疹、瘙痒 | 抗生素、部分中成药 |

出现以上表现应停药并联系医生，不要自行继续服用。

## 四、家属可做的事

1. 协助整理药盒，按早/中/晚分格，贴上大字标签。
2. 定期检查药品有效期，清理过期药。
3. 关注老人是否出现漏服、重复服药，及时提醒。

> 免责声明：以上内容为健康科普，不构成处方建议，具体用药请遵医嘱。
