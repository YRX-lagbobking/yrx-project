# 老年人心率与血氧异常的居家观察

## 一、心率参考范围

- 静息心率常见参考范围：60~100 次/分钟。
- 持续 >100 次/分钟提示心动过速，可能与发热、感染、甲亢、心律失常、心衰有关。
- 持续 <50 次/分钟提示心动过缓，可能与传导阻滞、甲状腺功能减退、部分降压药有关。
- 心率 >120 次/分钟或 <50 次/分钟属于需要重点关注的范围。

## 二、血氧饱和度（SpO2）参考范围

- 正常范围：95%~100%。
- 低于 94% 需关注，可能与呼吸功能不全、肺部感染、睡眠呼吸暂停有关。
- 低于 90% 属临床紧急情况，提示明显缺氧，应立即就医。

## 三、需要立即就医的组合信号

| 组合 | 可能提示 |
| :--- | :--- |
| 心率升高 + 血氧下降 | 心衰加重、肺栓塞、呼吸衰竭 |
| 血压升高 + 心率升高 | 高血压急症、应激状态 |
| 心率下降 + 意识模糊 | 严重心动过缓、脑供血不足 |

## 四、居家应急步骤

1. 让老人立即坐下或半卧，解开衣领，保持安静，不要走动。
2. 复测心率、血压、血氧各一次，记录数值与时间。
3. 出现胸痛、呼吸困难、意识模糊、口唇发紫，立即拨打 120，同时通知家属。
4. 随身携带既往病史与用药清单，便于急救人员判断。

> 免责声明：以上内容为健康科普，不构成诊断与处方。任何急性症状请立即就医。
