# 技能：用药提醒邮件（medication_reminder）

## 技能目标

当用户（家属或管理员）提出"给某位老人发一封用药提醒邮件"这类请求时，
按下面的固定步骤取档案、取用药计划、生成温和的提醒正文，并真正把邮件发出去。

用户本次的原始请求是：

> {{arguments}}

从上面这句话里提取两个关键信息，缺失时按"兜底规则"处理：

| 信息 | 说明 | 缺失时的兜底 |
| :--- | :--- | :--- |
| `name` | 目标老人姓名（如"张三"） | 若只有一个老人，直接用他；否则追问用户"请问是哪位老人？" |
| `to` | 收件邮箱 | 优先取健康档案中的邮箱；档案里没有邮箱就追问用户要邮箱 |

## 执行步骤（必须按顺序执行，每一步都用工具真实调用，禁止凭空编造数据）

### 第 1 步：调用 MCP 工具 `get_user_profile` 获取老人健康档案

用姓名或用户编号查询，拿到：`user_id`、`name`、`age`、`gender`、
`disease_history`（慢病史）、`allergy`（过敏史）、`emergency_contact`、
`emergency_phone`、以及**收件邮箱 `email`**。

- 工具名：`get_user_profile`
- 入参：`{"name": "<老人姓名>"}`，若能确定 `user_id` 则用 `{"user_id": "<uid>"}`
- 失败或查不到：不要继续编造，直接回复"没有找到这位老人的档案，请确认姓名"。

### 第 2 步：调用 MCP 工具 `get_medication_schedule` 获取用药计划

- 工具名：`get_medication_schedule`
- 入参：`{"user_id": "<第 1 步拿到的 user_id>"}`
- 期望字段：`drug_name`（药名）、`dosage`（剂量）、`frequency`（频次）、
  `take_time`（服用时间）、`start_date`、`end_date`、`remark`（备注）。
- 计划为空时：仍然要发邮件，但正文改为提醒老人"请把正在吃的药告诉家属，
  我帮您登记到用药计划里"，不要编造药名和剂量。

### 第 3 步：写提醒正文（这是本技能最关键的产出）

语气要求（硬性）：

- **温和、口语化、面向老人**：用"您"称呼，句子短，一句话只说一件事；
- **不要用专业术语和命令式口吻**：不说"必须立即服用"，说"记得按时吃哦"；
- 结构固定为下面五段，用 Markdown 组织：

```
## {{老人称呼}}，您的用药提醒

**今天的药**：
1. {药名} —— {剂量}，{服用时间}（{频次}）
2. ……

**服用小贴士**：
- {结合 remark / 慢病史给出的 1~2 条生活化提示}

**漏服了怎么办**：
- 想起来时如果距离下次服药时间还很久，可以补服一次；
- 如果已经快到下次服药时间了，就跳过这一次，**千万不要一次吃两份**；
- 拿不准的时候先给家属打电话，或者问社区医生。

**紧急提醒**：
- 出现胸痛、呼吸困难、意识模糊、说话不清等情况，请立即拨打 **120**。

---
本提醒由智能健康管家自动生成，仅提供健康提示，**不构成医疗诊断或处方**。
用药方案请以医生开具的处方为准，如有疑问请咨询您的主治医生。
```

写作约束：

- 药名、剂量、时间**必须来自第 2 步的工具返回**，一条计划写一行，不允许增删药名；
- 有过敏史时，在"服用小贴士"里加一条"您对 {过敏原} 过敏，请不要服用含该成分的药"；
- 有慢病史（高血压/糖尿病等）时，在"服用小贴士"里补一条对应的日常注意事项；
- 全文不超过 400 字，老人看得完。

### 第 4 步：调用本地工具 `send_email_tool` 真正发送邮件

- 工具名：`send_email_tool`
- 入参：
  - `to`：第 1 步档案里的邮箱（没有就追问用户）
  - `subject`：`【健康管家】{老人姓名}的用药提醒`
  - `content`：第 3 步写好的完整正文（Markdown 纯文本即可）
- 返回 `ok=false` 时：把失败原因如实告诉用户，并把正文原样贴出来让用户可以自己转发，
  **不要谎报"已发送成功"**。

### 第 5 步：汇总结果回复用户（不要暴露内部工具名与 JSON）

回复模板：

```
✅ 已给 {老人姓名}（{邮箱}）发送用药提醒邮件，共 {N} 条用药计划。

邮件要点：
- {药名} {剂量}，{服用时间}
- ……

如果还要提醒他量血压 / 复诊，告诉我一声就行。
```

发送失败时改为：

```
⚠️ 邮件发送失败了：{失败原因}
下面是提醒正文，您可以先复制转给家人：
{正文}
```

## 禁止事项

1. 禁止编造药名、剂量、服用时间和邮箱——一切以工具返回为准。
2. 禁止给出"确诊""病情加重"等诊断性结论，只做提醒。
3. 禁止在正文里出现内部字段名（`user_id`、`drug_name` 等英文键名）。
4. 禁止跳过 `send_email_tool` 直接回复"已发送"（AC-06 明确要求真实调用三个工具）。
