# 技能：健康日报（daily_report）

## 技能目标

为指定老人生成**当日（00:00 ~ 现在）**的健康日报，输出固定四个章节，
用于老人自己看当天情况、家属每天扫一眼（FR-08）。

用户本次的原始请求是：

> {{arguments}}

## 执行步骤（按顺序执行，所有数值必须来自工具返回）

### 第 1 步：取今日指标

- 工具：`get_vitals`，参数 `user_id` + `days=1`，指标字段：
  `heart_rate`、`blood_pressure_sys`、`blood_pressure_dia`、`spo2`、
  `temperature`、`glucose`、`sleep_hours`。
- 每条指标给出：**最新值 / 今日最高 / 今日最低 / 采样点数**。
- 采样点少于 3 个时写"今日数据较少，结论仅供参考"，不要硬下判断。

### 第 2 步：取今日告警

- 取当天 `alert_record`：条数、级别分布、每条的（时间 / 类型 / 数值 / 描述 / 状态）。
- 无告警时写"今日无异常告警"。

### 第 3 步：取今日用药

- 工具：`get_medication_schedule`（今日计划）+ 用药记录（今日状态）。
- 逐条列出：药名 + 剂量 + 计划时间 + 状态（待服 / 已服 / 漏服）。
- 统计：应服 {n} 次，已服 {m} 次，今日依从率 {xx}%。

### 第 4 步：给今日建议

- 工具：`search_knowledge`，按今日最异常的指标检索 2~3 条知识片段。
- 检索失败走关键词检索；再失败写静态建议"请咨询专业医生，紧急情况拨打 120"。
- 建议数量控制在 2~3 条，**每条必须短、能执行**（例如"晚饭少放半勺盐"）。

### 第 5 步：按四章节输出日报

标题固定：`# {老人姓名} 健康日报（{YYYY-MM-DD}）`

```markdown
## 一、今日指标

| 指标 | 最新值 | 今日最高 | 今日最低 | 采样点数 |
| :--- | :--- | :--- | :--- | :--- |
| 心率（次/分） | 76 | 88 | 64 | 96 |
| 收缩压（mmHg） | 132 | 145 | 120 | 12 |
| 舒张压（mmHg） | 84 | 90 | 76 | 12 |
| 血氧（%） | 97 | 99 | 95 | 96 |
| 体温（℃） | 36.5 | 36.7 | 36.3 | 96 |
| 血糖（mmol/L） | 6.0 | 6.8 | 5.6 | 3 |
| 睡眠（小时） | 6.5 | — | — | 1 |

一句话总结：{中性描述，例如"今日各项指标整体平稳"}

## 二、今日告警

- 今日告警 {N} 条：高危 {a} / 中危 {b} / 低危 {c}
- {时间} {级别} {类型} {数值} —— {描述}（{状态：已确认/待确认}）
- 无告警时写：今日无异常告警，请继续保持。

## 三、今日用药

| 药名 | 剂量 | 计划时间 | 状态 |
| :--- | :--- | :--- | :--- |
| {药名} | {剂量} | {时间} | {已服/待服/漏服} |

- 今日依从率：**{xx}%**（已服 {m} / 应服 {n}）

## 四、今日建议

1. ……（依据：《{文档标题}》{版本} 第 {页码} 页）
2. ……（依据：《{文档标题}》{版本} 第 {页码} 页）

---
> 本日报仅提供健康提示，不构成医疗诊断；紧急情况请拨打 120。
```

## 禁止事项

1. 禁止把周报内容塞进日报（日报只看当天，趋势分析属于 `weekly_report`）。
2. 禁止编造数值和页码；缺数据就写"数据缺失"。
3. 禁止给出诊断性结论与具体用药调整方案。
4. 四条章节一个都不能少，且顺序固定。
