# 开发规范与接口契约（V1.0）

> 本文件是本项目的**唯一接口事实来源**。任何模块实现与本文冲突时，以本文为准；确需变更，先改本文件并同步影响方。
> 目录常量：`APP = app/`。项目根目录名 `agent_project`，Python 包根为 `app`，所有导入必须写全路径，例如 `from app.core.config import settings`。

---

## 0. 技术基线与代码风格

| 项 | 规定 |
| :--- | :--- |
| Python | 3.11+；文件编码 UTF-8；注释与文档字符串用中文 |
| 框架 | FastAPI + LangGraph + LangChain（`create_agent`） |
| 风格 | 参照 `exam_0914`：模块顶部用三引号中文说明块；关键行加中文注释；文件末尾保留 `if __name__ == "__main__":` 自测块 |
| 日志 | 统一 `from app.core.logger import logger`，禁止裸 `print` 作为唯一输出（允许保留少量业务 print 便于学习调试，但关键路径必须 `logger`） |
| 配置 | 一律 `from app.core.config import settings`，**禁止**在业务模块里散落 `os.getenv` |
| 可选依赖 | `vosk`、`pyaudio`、`edge_tts`、`pymilvus`、`chromadb`、`influxdb_client_3`、`celery`、`mcp`、`psycopg_pool`、`redis` 一律**函数内延迟导入**并 `try/except ImportError` 处理，保证"未安装依赖时模块仍可导入、接口可降级"。`fastapi`、`pydantic`、`langchain*`、`langgraph`、`pymysql`、`python-dotenv` 可以顶层导入 |
| 同步/异步 | DAO、tools、celery task 为**同步**；节点、路由器、记忆层为**异步**。异步节点内调用同步 DAO 是允许的（本项目为教学/演示规模），但必须注释说明生产应改连接池/异步 |
| 返回风格 | 统一"永不抛异常给上层"：工具函数捕获异常后返回错误字符串或降级结果；节点捕获异常后返回 `task_results[task] = {"status":"error","msg":...}` |

```
节点集合: planner, manager, intent, data_check, rag, risk, report, remind, notify, summarize, chat
边: START→planner；planner→manager；{intent,data_check,rag,risk,report,remind,notify,chat}→manager；summarize→END

manager_node(state) -> Command:
  1. queue = list(state.get("task_queue", []))
  2. retry_count = state.get("retry_count", 0)
     若 current_task 对应 task_results[task]["status"] == "error"：
         retry_count < 3 → 把该任务重新 insert(0) 回 queue，retry_count+1，goto 同名 worker
         否则 → goto "chat"
  3. 若 queue 为空：
         task_results 为空 → goto "summarize"
         仅含 "chat" → goto END
         否则 → goto "summarize"
  4. current = queue.pop(0)；name = current["task"]
     route_map = {"intent":"intent","vitals":"data_check","knowledge":"rag","risk":"risk",
                  "medication":"remind","report":"report","notify":"notify",
                  "emotion":"chat","chat":"chat"}
     name 不在 route_map → current = {"task":"chat","args":{"content":<原任务>}}，logger.warning 记录未知任务，goto "chat"
  5. return Command(update={"task_queue":queue,"current_task":current,"retry_count":retry_count}, goto=...)
```

节点通用签名与返回（**除 manager 外全部为 `async def`**）：

| 节点 | 签名 | 必须写入的返回值 |
| :--- | :--- | :--- |
| `planner_node` | `async def planner_node(state)` | `task_queue`、`health_step="planned"`、`task_results={}`、`retry_count=0` |
| `intent_node` | `async def intent_node(state)` | `intent`、`emotion`、`health_step="intent"` |
| `data_check_node` | `async def data_check_node(state)` | `vitals`、`data_available`、`data_missing`、`task_results`（含 `"vitals"` 键）、`health_step="data_check"` |
| `rag_node` | `async def rag_node(state)` | `knowledge`、`task_results`（`"knowledge"` 键）、`health_step="rag"` |
| `risk_node` | `async def risk_node(state)` | `risk_level`、`risk_reasons`、`anomalies`、`need_notify`、`task_results`（`"risk"` 键）、`health_step="risk"` |
| `report_node` | `async def report_node(state)` | `report_type`、`report_content`、`report_path`、`task_results`（`"report"` 键）、`health_step="report"` |
| `remind_node` | `async def remind_node(state)` | `medication_list`、`remind_content`、`task_results`（`"medication"` 键）、`health_step="remind"` |
| `notify_node` | `async def notify_node(state)` | `notify_channel`、`notify_result`、`task_results`（`"notify"` 键）、必要时 `need_human_confirm`、`health_step="notify"` |
| `summarize_node` | `async def summarize_node(state)` | `final_answer`、`messages`、`health_step="done"` |
| `chat_node` | `async def chat_node(state)` | `final_answer`、`messages`、`task_results`（`"chat"` 键，或在未知任务时用 `f"unknown_{n}"` 键）、`health_step="done"` |

流式节点（`chat_node`、`summarize_node`、`report_node`）必须用 `get_stream_writer()` 逐段 `write(fragment)` 输出给前端；其余节点通过 `messages` 追加 `AIMessage` 记录过程（前端只展示流式片段，`messages` 用于状态与记忆）。

失败降级约定：节点内部 `try/except`；失败时写 `task_results[task] = {"status":"error","msg":str(e)}` 并保留其它字段默认值。
