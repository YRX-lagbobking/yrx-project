# 接口文档

> 本文是《需求文档》9.1 / 9.2 / 9.3 三张表的**展开版**，是前后端联调的直接依据。
> 路径事实来源是《需求文档》第 9 节与《开发规范与接口契约》第 18、21 节，**不得自创路径**。

## 0. 通用约定

| 项 | 约定 |
| :--- | :--- |
| 服务地址 | 开发态 `http://localhost:8000`；容器部署同端口 |
| 数据格式 | 除 SSE / WebSocket / 文件下载外，一律 `application/json; charset=utf-8` |
| 鉴权方式 | `Authorization: Bearer <JWT>`（契约第 4 节 `get_current_user` 依赖解析） |
| 免鉴权接口 | `GET /`、`GET /health`、`POST /user/login`、`POST /user/register`、静态资源 `/static/*` |
| 角色 | `elder` 老人 / `family` 家属 / `admin` 管理员 |
| 成功返回 | 直接返回业务字段，或 `{"code": 0, "msg": "ok", "data": ...}` 包裹（前端两种都做了兼容） |
| 错误返回 | `{"detail": "错误说明"}`（FastAPI 标准；Pydantic 校验失败时 `detail` 为数组） |
| 分页 | 本期列表接口用 `limit` 控制条数，默认 20 |
| 参数校验 | 全部入参用 Pydantic 校验类型与范围；SQL 一律参数化（NFR-03） |

### 0.1 统一错误码

| HTTP 状态码 | detail 示例 | 触发场景 |
| :--- | :--- | :--- |
| `200` | — | 成功 |
| `400` | `"用户名已存在"` / `"参数格式错误"` | 业务校验失败 |
| `401` | `"未登录或 Token 无效"` / `"Token 已过期"` | 缺 `Authorization` 头、签名错误、已过期 |
| `403` | `"无权访问该用户数据"` | 老人查他人（AC-19）、家属未绑定（AC-20）、非 admin 调管理接口 |
| `404` | `"会话不存在"` / `"报告未生成"` | 资源不存在 |
| `409` | `"会话忙，请稍后再试"` | 同一会话并发请求被分布式锁拒绝（AC-24） |
| `422` | Pydantic 校验错误数组 | 入参类型/范围不合法 |
| `500` | `"服务器内部错误"` | 未预期异常（关键路径已尽量降级，不应出现） |
| `503` | `"服务降级中：只读模式"` | `mode=readonly` 时收到写操作 |

### 0.2 错误返回示例

```json
{
  "detail": "无权访问该用户数据"
}
```

```json
{
  "detail": [
    {
      "type": "missing",
      "loc": ["body", "user_name"],
      "msg": "Field required"
    }
  ]
}
```

## 1. HTTP / SSE 接口（需求文档 9.1）

### 1.1 `POST /user/register` —— 注册

| 项 | 内容 |
| :--- | :--- |
| 鉴权 | 否 |
| Content-Type | `application/json` |
| 说明 | 注册新用户并选择角色（elder / family） |

**请求参数**

| 参数 | 类型 | 必填 | 说明 |
| :--- | :--- | :--- | :--- |
| `user_name` | string | 是 | 用户名，全局唯一 |
| `password` | string | 是 | 明文密码，服务端 `hash_password` 后入库 |
| `email` | string | 否 | 邮箱（家属通知与用药提醒用） |
| `phone` | string | 否 | 手机号 |
| `role` | string | 否 | `elder`（默认）/ `family` |

**请求示例**

```json
{
  "user_name": "zhangsan",
  "password": "123456",
  "email": "zhangsan@example.com",
  "phone": "13800000001",
  "role": "elder"
}
```

**响应示例**

```json
{
  "code": 0,
  "msg": "注册成功",
  "data": {
    "user_id": "u001",
    "user_name": "zhangsan",
    "role": "elder"
  }
}
```

**错误码**：`400` 用户名已存在 / 密码强度不足；`422` 参数缺失。

### 1.2 `POST /user/login` —— 登录（签发 JWT）

| 项 | 内容 |
| :--- | :--- |
| 鉴权 | 否 |
| 说明 | 校验用户名（或邮箱）+ 密码，返回 JWT 与用户信息；前端存 `localStorage.token` |

**请求参数**

| 参数 | 类型 | 必填 | 说明 |
| :--- | :--- | :--- | :--- |
| `user_name` | string | 是 | 用户名或邮箱 |
| `password` | string | 是 | 明文密码 |

**请求示例**

```json
{
  "user_name": "zhangsan",
  "password": "123456"
}
```

**响应示例**

```json
{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJ1c2VyX2lkIjoidTAwMSIsInJvbGUiOiJlbGRlciJ9.xxxxx",
  "user_id": "u001",
  "user_name": "zhangsan",
  "role": "elder",
  "email": "zhangsan@example.com"
}
```

**前端跳转规则**：`elder → /static/chat.html`，`family → /static/family.html`，`admin → /static/report.html`。

**错误码**：`400` 用户名或密码错误；`401` 账号被停用。

### 1.5 `POST /create_session` —— 创建 / 校验会话

| 项 | 内容 |
| :--- | :--- |
| 鉴权 | JWT |
| 说明 | 首次请求不带 `session_id` → 创建新会话并返回；带 `session_id` → 校验归属（Redis `session:<uuid>`），不属于当前用户则拒绝 |

**请求参数**

```json
}
```

**响应示例**（直接返回字符串，或包裹在 data 里，前端两种都兼容）

```json
{
  "data": "8f3b2c1a-9d4e-4f6a-b7c8-1e2d3f4a5b6c"
}
```

**错误码**：`403` 会话不属于当前用户；`401` 未登录。

### 1.6 `GET /chat` —— SSE 流式问询（核心接口）

| 项 | 内容 |
| :--- | :--- |
| 鉴权 | JWT（`Authorization` 头；`EventSource` 不支持自定义头，因此额外支持 `?token=` 查询参数） |
| 响应类型 | `text/event-stream` |
| 说明 | 进入 LangGraph 图执行，逐段推送 AI 回复片段 |

**请求参数**

| 参数 | 位置 | 类型 | 必填 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| `question` | query | string | 是 | 用户问题原文 |
| `user_id` | query | string | 是 | 提问用户 |
| `session_id` | query | string | 是 | 会话编号（Checkpointer 的 `thread_id`） |
| `token` | query | string | 否 | JWT，供 EventSource 使用 |

**请求示例**

```
GET /chat?question=%E6%88%91%E4%BB%8A%E5%A4%A9%E8%A1%80%E5%8E%8B%E6%80%8E%E4%B9%88%E6%A0%B7&user_id=u001&session_id=8f3b2c1a-...&token=eyJhbGciOi...
```

**SSE 事件示例**

```
data: {"data": "您今天的血压是 ", "done": false}

data: {"data": "128/82 mmHg，", "done": false}

data: {"data": "整体比较平稳。", "done": false}

data: {"data": "", "done": true}
```

**流式写入来源**：`chat_node` / `summarize_node` / `report_node` 用 `get_stream_writer()` 逐段 `write(fragment)`。

**错误码**：`401` Token 无效；`403` 无该 `user_id` 的访问权限；`409` 会话忙（AC-24）。

### 1.7 `POST /chat/skill` —— 指定 Skill 触发

| 项 | 内容 |
| :--- | :--- |
| 鉴权 | JWT |
| 说明 | 由前端显式指定技能（跳过 Planner 的意图判断），走 `HealthGraphAgent.chat_skill(...)` |

**请求参数**

| 参数 | 类型 | 必填 | 说明 |

| `user_id` | string | 是 | 用户 |

### 1.12 `GET /report/download` —— 报告导出 Word

| 项 | 内容 |
| :--- | :--- |
| 鉴权 | JWT |
| 响应类型 | `application/vnd.openxmlformats-officedocument.wordprocessingml.document` |
| 说明 | 用 `python-docx` 生成 docx 并返回 `FileResponse` |

**请求参数**

| 参数 | 位置 | 类型 | 必填 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| `user_id` | query | string | 否 | 报告对象 |
| `type` | query | string | 是 | `daily` / `weekly` |

**请求示例**

```
GET /report/download?user_id=u001&type=weekly
Authorization: Bearer eyJhbGciOi...
```

**响应头示例**

```
Content-Type: application/vnd.openxmlformats-officedocument.wordprocessingml.document
Content-Disposition: attachment; filename*=UTF-8''%E5%81%A5%E5%BA%B7%E5%91%A8%E6%8A%A5.docx
```

**前端下载方式**（必须带 Token，因此用 fetch + blob）：

```javascript
fetch('/report/download?user_id=u001&type=weekly', {
  headers: { 'Authorization': 'Bearer ' + localStorage.getItem('token') }
})
  .then(res => res.blob())
  .then(blob => {
    const a = document.createElement('a');
    a.href = URL.createObjectURL(blob);
    a.download = '健康周报.docx';
    a.click();
  });
```

**错误码**：`404` 报告未生成；`403` 无权限；`500` python-docx 未安装。

## 2. WebSocket 接口（需求文档 9.2）

### 2.1 `WS /voice/ws` —— 语音识别（双向）

| 项 | 内容 |
| :--- | :--- |
| 鉴权 | JWT（`?token=<JWT>` 查询参数，或连接后首帧发 Token） |
| 说明 | 服务端基于 Vosk 流式识别，**支持连续多句**（AC-01）；随时可停（AC-02） |

**服务端 → 客户端消息**

| 消息 | 说明 |
| :--- | :--- |
| 纯文本 `开始说话` | 模型与麦克风就绪，可以开始说话（前端据此禁用"开启语音"按钮） |
| 纯文本 `<识别文本>` | 一句话识别完成的结果（前端填入输入框并自动发送） |
| JSON `{"type":"asr","text":"我今天血压怎么样","final":true}` | 结构化形式，前端两种都兼容 |

**客户端 → 服务端消息**

| 消息 | 说明 |
| :--- | :--- |
| 纯文本 `停止` | 停止监听并释放音频流（1s 内生效） |
| JSON `{"action":"stop"}` | 同上，结构化形式 |

**前端调用示例**

```javascript
const url = 'ws://' + location.host + '/voice/ws?token=' + encodeURIComponent(localStorage.getItem('token'));
const ws = new WebSocket(url);
ws.onmessage = (e) => {
  const text = String(e.data || '').trim();
  if (text.indexOf('开始说话') > -1) { /* 禁用按钮，进入聆听态 */ return; }
  send(text);   // 识别结果自动发送
  ws.close();
};
// 停止
ws.send('停止');
```

**异常**：模型缺失 / 麦克风被占用时，服务端发送一条提示文本后正常关闭，不抛异常。

### 2.2 `WS /ws/notify?user_id=` —— 告警实时推送（服务端 → 客户端）

| 项 | 内容 |
| :--- | :--- |
| 鉴权 | JWT（`token` 查询参数） |
| 说明 | 由 `ConnectionManager` 维护 `user_id → websocket` 映射，告警时服务端主动推送 |

**推送消息示例**

```json
{
  "type": "health_alert",
  "alert_id": 1,
  "level": "高危",
  "alert_type": "blood_pressure_high",
  "value": "186",
  "message": "检测到收缩压 186 mmHg，超过安全范围。请先安静休息 5 分钟后复测；若伴头痛、胸闷、视物模糊，请立即拨打 120。",
  "action": "voice_play"
}
```

**前端处理**：弹窗 + EdgeTTS 播报 + 显示"我已知道"按钮 → `POST /alert/{alert_id}/confirm`。

**心跳与重连**：服务端可发 `{"type":"ping"}`；前端 `onclose` 后 5 秒自动重连。

**ConnectionManager 接口（契约第 18 节）**

```python
class ConnectionManager:
    async def connect(self, user_id: str, websocket) -> None
    def disconnect(self, user_id: str) -> None
    async def send_to_user(self, user_id: str, data: dict) -> bool
    def is_online(self, user_id: str) -> bool

ws_manager = ConnectionManager()   # 模块级单例
```

### 3.0 通用约定

| 项 | 约定 |
| :--- | :--- |

| HTTP 状态码 | 说明 |
| :--- | :--- |
| `200` | 调用成功（`ok` 字段表示业务是否成功） |

| `422` | `arguments` 参数类型错误 |
